### Galahax
A Galaga-style shooter game about destroying hacker ships. Made completely in Python using Pygame. 

You are an electrical plug trying to protect against electrical components shorting the socket. There are a variety of components, but some other objects want to short the socket too. Use your power to overload and destroy the components. 

Use the arrow keys or WASD to move. Space or Enter to shoot. Works with number pad.
