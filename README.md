## Games
- Galahax
- Self Sabotage

### Galahax
A Galaga-style shooter game about destroying hacker ships. Made completely in Python using Pygame. 

You are an electrical plug trying to protect against electrical components shorting the socket. There are a variety of components, but some other objects want to short the socket too. Use your power to overload and destroy the components. 

**How to Play**

Use the arrow keys or WASD to move. Space or Enter to shoot. Works with number pad.

### Self Sabotage
Self Sabotage is a game where you start as a cannon and shoot into "The Box". Then you become the player and have to dodge your shots within "The Box". Remember where you put your shots!!! In later levels, there are also mines and bouncing shots. Made in Python using Pygame, images made in Microsoft Paint.

**How to Play**

Use the arrow keys or WASD to move. Right-click to shoot and place mines. Works with number pad.
